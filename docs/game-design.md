# 《dimbro》Web Demo 设计文档

> 版本：v0.4 · 类型：俯视角自动射击 Roguelite · 平台：桌面浏览器  
> Demo 目标：单局 10–15 分钟，完整跑通「选程序员 → 8 波战斗 → 属性升级 → 商店 → Boss → 结算」  
> 原创说明：玩法灵感来自「割草 + 轮次成长」类型，但不复用《土豆兄弟》的角色、数值表、文案、美术或音频素材。角色设定来自 DimAgent 程序员，游戏名称为 **dimbro**。

---

## 1. 一句话概念

一次版本发布事故后，DimAgent 的程序员们被卷进失控的构建空间「dimbro」。他们套上值班室里临时拼装的外骨骼，在机械废土中边跑边自动开火，靠每波结束后的「回路升级」和商店改装，撑过 8 波故障进程，最后关停熔炉核心。

### 核心体验

1. **30 秒进入战斗**：跳过复杂教学，WASD 移动即可开打。
2. **自己人当主角**：夕阳针、Simon、Junyi 是 DimAgent 程序员们的 Q 版分身；夕阳针与 Simon 各有两个带名字的专属被动，Junyi 暂时禁用。
3. **每波都有变化**：升级三选一 + 商店四选 N，构筑感持续推进。
4. **操作简单但不无脑**：自动攻击负责输出，走位负责躲弹幕、吃金币、绕开近战怪。
5. **短局可复盘**：失败后能明确说出「这波我该先堆护甲 / 换武器 / 买回复」。

### Demo 设计目标

- 一条完整可玩的游戏流程，而不是只有战斗场景的技术演示。
- 2 位可玩 DimAgent 程序员（夕阳针、Simon）+ 1 个禁用占位角色 Junyi，5 种武器、18 张属性卡（12 纯正面 + 6 风险）、10 种商店模块。
- 5 类敌人 + 1 个具有阶段变化的 Boss。
- 所有视觉和音效可程序化生成，不依赖外部素材，避免版权问题。
- 桌面端 1080p / 60 FPS 稳定运行，同时兼容 1280×720。

### Demo 不做

- 手机触屏、手柄、联机、排行榜、成就。
- 局外成长、角色解锁、永久货币。
- 多地图、随机地图、障碍物寻路。
- 武器合成、复杂元素反应、剧情分支。
- 完整音乐制作；Demo 使用程序化循环音乐与音效，不引入外部音频素材。
- 音频默认关闭，玩家可在首页、设置和暂停菜单中分别开启音乐与音效。

## 2. 核心循环与单局结构

```text
首页
  ↓ 开始游戏
选择程序员
  ↓
第 1 波战斗（25–40 秒）
  ↓ 存活
波次结算
  ↓
属性升级（三选一）
  ↓
商店（购买武器 / 模块，刷新）
  ↓
下一波
  ↓ 重复第 1–7 波
Boss 波（第 8 波）
  ↓
胜利结算 / 失败结算
  ↓
再来一局 or 返回首页
```

### 单局节奏

| 阶段 | 时长 | 玩家决策 |
|---|---:|---|
| 首页 / 选程序员 | 30 秒 | 选择玩法风格 |
| 单波战斗 | 25–40 秒 | 走位、拾取、火力覆盖 |
| 波次结算 + 升级 | 10–20 秒 | 从 3 张属性卡中选 1 张 |
| 商店 | 20–45 秒 | 买武器、买模块、刷新、替换装备 |
| 完整一局 | 10–15 分钟 | 构筑、取舍、挑战 Boss |

### 轮次规则

- Demo 共 **8 波**，前 7 波为普通波次，第 8 波为 Boss 波。
- 每完成第 1–7 波，固定获得 **1 次属性升级**。
- Boss 波胜利后直接进入胜利结算，不再进入商店。
- 生命值跨波次保留；每波开始时不会自动回满。
- 玩家死亡即本局结束，不提供「原地复活」。
- 普通角色在波次结束时只结算已拾取的金币，场上未拾取金币会丢失；Simon 的专属被动可收走全部漏捡金币。
- 每波结束显示金币结算：已拾取、完成奖励、Simon 自动修复、未拾取损失。

| 波次 | 时长 | 敌人构成 | 特殊事件 | 完成奖励 |

## 3. 页面与界面设计

整体采用 **单页游戏外壳 + 状态机切屏**，不做传统网页路由。

### 3.1 首页 Home

```text
┌────────────────────────────────────────────────────┐
│  [音频开关]                              v0.4 DEMO │
│                                                    │
│                    d i m b r o                     │
│          DIMAGENT PROGRAMMERS vs. THE BUILD        │
│          “先别重启，让我看看日志。”                 │
│                                                    │
│              [ 开始任务 ]                           │
│              [ 继续任务 ]   ← 有存档时显示          │
│              [ 操作说明 ]                           │
│                                                    │
│  DimAgent 值班组 · 机械废土 · 单局 10–15 分钟        │
└────────────────────────────────────────────────────┘
```

- 背景：低亮度工厂地面、故障终端雪花屏和缓慢旋转的齿轮剪影。
- 标题使用小写 `dimbro` 字标，副标题强调 DimAgent 程序员身份。
- 主按钮使用琥珀色高亮；次要按钮为描边样式。
- 「继续任务」读取 LocalStorage 存档，从下一波开始。
- 首次进入自动展示简短操作说明（< 10 秒可关闭）。

- 三张卡片同时展示，包含头像、名字、定位标签、初始武器和核心被动组合。
- 可选角色为 **夕阳针**、**Simon**；**Junyi 暂不可选**，卡片灰显并标注「能力设计中」。

| 夕阳针 | 光轨追焦 | 连续移动 1 秒：移速 +10%、暴击率 +8%；停下超过 1 秒失效 |

| Junyi | 未定 | 角色暂未完成，Demo 中禁用 |

HUD 规则：

- 顶部：波次、倒计时、暂停按钮；Boss 波显示 Boss 血条与阶段标记。
- 左下：玩家生命条、护甲值、已拥有武器槽位，以及当前角色的两个被动图标。
- 选择 Simon 时，维修护盾显示在生命条右侧，以金币环和层数表示；其他角色不显示该槽位。
- RESET 激活时显示高亮倒计时条；画面边缘出现短促扫描线 / 色差故障效果，结束后恢复。
- 光轨追焦激活时，被动图标亮起并显示「移速 +10% / 暴击 +8%」；身后拖出短促光轨和相机对焦框，停下超过 1 秒后熄灭。
- 右下：金币数量，获得时数字跳动。
- 武器图标显示冷却环与等级点；冷却在 Canvas / CSS 中实时推进，不依赖状态刷新。
- 波次最后 5 秒，倒计时变红并脉冲；地上未拾取金币同步闪烁，提示普通角色「结束后将丢失」。
- 低血量（< 30%）屏幕边缘出现红色暗角，不遮挡战场。
- 玩家受伤时短暂白闪 + 受击震屏；精英和 Boss 有独立血条。
- 敌人出生点提前 0.6 秒显示地面警示圈，避免无预警贴脸。
- 波次结束后的金币结算条展示：已拾取、完成奖励、Simon 自动修复、未拾取损失。

#### 交互方式

| 操作 | 键位 |
|---|---|
| 移动 | WASD / 方向键 |
| 自动攻击 | 无需操作，自动瞄准最近敌人 |
| 暂停 | Esc / P |
| 选择目标 | 不支持手动瞄准（保持操作轻量） |
| 菜单交互 | 鼠标点击 / 键盘 Tab + Enter |

> 不加入冲刺。Boss 弹幕依靠移速升级和走位规避；这是构筑中「移速」的价值来源。

```text
└──────────────────────────────────────────────────────────┘
```

- 每波商店生成 4 个商品；武器和模块混合出现。
- 至少保证 1 个武器商品，直到 4 个武器槽全满；否则不再生成未拥有的武器。
- 刷新费用：第 1 次 5 金币，之后每次 +4。
- 每件商品只能买一次；买走后位置变空。
- 装备栏始终可见，4 个武器槽。点武器可查看详情 / 出售（返还 50%）。
- 未拥有的武器购买后占用空槽；槽满时弹出槽位替换选择，被替换武器返还 50% 金币。
- 重复购买已拥有武器：该武器升 1 级，最高 Lv.3。每级伤害 +25%，冷却 -6%。
- 「进入下一波」按钮是唯一出口；离开商店后本商店关闭，不能回退。
- 商店与升级页均使用暂停态，背景保留模糊的战斗场景，避免页面跳脱。

### 3.6 结算页面

**胜利**

- 展示：使用角色、用时、击杀数、造成伤害、最高单次伤害、剩余生命。
- 按钮：再来一局 / 返回首页。
- 背景：工厂停机，粒子光柱，Boss 残骸。

**失败**

- 展示：坚持到第几波、击杀数、造成伤害、构筑摘要。
- 按钮：重新开始 / 返回首页。
- 不提供同波重试，避免破坏 Roguelite 的风险感。

### 3.7 暂停页

- 继续、重新开始、返回首页、音乐开关、音效开关、震屏开关。
- 暂停时游戏循环停止更新，但 Canvas 保留最后一帧并加暗色蒙层。
- 关闭浏览器标签页时当前对局不保证可恢复；仅在波次开始 / 商店结束时写入存档。

## 4. 战斗系统

### 4.1 战场

- 世界尺寸固定 **1600 × 900**，16:9，等比缩放到浏览器，保留黑边。
- 单屏竞技场，不滚动摄像机；玩家始终在同一屏幕内移动。
- 四周为工厂边界，有少量纯装饰性地板标记、油渍、管线，不放障碍物。
- 玩家和敌人均限制在离边界 24px 的可行走区域内。
- 敌人在四条边随机传送门出现，出生前有 0.6 秒警示；出生点距离玩家至少 260px。
- 场上敌人上限 60；达到上限时暂停刷新，直到低于 48。

### 4.2 玩家基础属性

| 属性 | 初始值 | 说明 |
|---|---:|---|
| 最大生命 | 65–90 | 角色间有差异 |
| 当前生命 | 最大生命 | 跨波保留 |
| 护甲 | 0 | 递减式减伤 |
| 伤害加成 | 0% | 影响所有武器 |
| 攻速加成 | 0% | 影响所有武器冷却 |
| 暴击率 | 5% | 上限 75% |
| 暴击伤害 | +50% | 即暴击造成 150% 伤害 |
| 移速 | 220 px/s | 基础值 |
| 生命回复 | 0/s | 每秒结算一次 |
| 拾取半径 | 80 px | 自动吸取金币 |
| 受击无敌 | 0.6s | 防止连续接触秒杀 |

### 4.3 伤害公式

**玩家造成伤害**

```text
单次伤害 = 武器基础伤害
         × (1 + 伤害加成)
         × (暴击 ? 1.5 + 暴击伤害加成 : 1)
         × 敌人承伤系数
```

- 同一来源的百分比加成相加；不同乘区相乘。
- 武器基础伤害以数据表中的 Lv.1 值为准，升级按比例提升。
- 内部保留浮点，显示时向下取整；最低伤害为 1。
- 暴击单独判定，每个投射物 / 每次近战命中独立触发。
- 敌人承伤系数暂定为 1；后续可用于护盾或弱点系统。

**玩家受到伤害**

```text
实际伤害 = 敌人基础伤害 × 30 / (30 + 护甲)
最低伤害 = 1
```

- 护甲 3 → 约 9.1% 减伤；护甲 10 → 25%；护甲 30 → 50%。
- 接触伤害每个敌人独立判定，但玩家受击后 0.6 秒无敌，期间仅播放闪白。
- 远程弹幕命中同样触发无敌帧，避免多个弹幕同帧叠加秒杀。

**攻速**

```text
实际冷却 = 武器基础冷却
         / (1 + 攻速加成)
         / (RESET 激活 ? 5 : 1)
```

- Demo 常规攻速加成软上限 +150%，常规状态实际冷却不低于 0.12 秒。
- RESET 的 ×5 攻速在常规冷却计算之后结算；触发期间冷却下限为 0.08 秒，避免武器动画与弹幕生成失控。
- Simon 的「Simon太强了」提供的 +50% 伤害直接计入伤害加成，与其他来源线性相加。
- 光轨追焦激活时额外提供 8 个百分点暴击率和 10% 移速；暴击率仍受 75% 上限限制，移速与其他加成线性相加。
- 攻速提升对高频武器收益更高，是构筑核心变量之一；攻速和武器数量会提高 RESET 的触发频率。

### 4.4 自动战斗规则

- 每把武器独立计时、独立索敌、独立开火。
- 默认索敌：攻击范围内距离玩家最近的敌人；距离相同时优先低血量。
- 近战武器攻击朝目标方向的扇形；目标死亡后本次攻击仍然结算。
- 投射物为圆形碰撞；命中后按穿透次数决定是否销毁。
- 敌人子弹不穿透，不碰撞其他敌人。
- 玩家可穿过敌人，不做实体碰撞推挤，避免卡位；敌人之间做轻微分离力，防止完全重叠。
- 磁吸：金币进入拾取半径后加速飞向玩家；波次结束时全图吸附。

```text
敌人生命 = 基础生命 × 0.8 × (1 + 0.12 × (波次 - 1))

```

- 精英使用上述成长；Boss 不参与波次成长，只吃全局 HP 系数。

- 表中敌人 HP 为数据表基础值；Boss 不参与波次成长，实战 HP 为 2200 × 0.8 = 1760。
- 每波在开战时按 `targetUnits` / `targetHp` 预生成刷怪队列：队列固定杂兵数量，并用 DP 逼近目标总血量（精英血量先从目标中扣除）。
- 队列按 `spawnWeights` 决定类型偏好，生成后在 ±5% 血量、±25% 权重内随机抖动并打乱顺序；同一波的总血量不会因类型随机而大幅漂移。
- 精英按 `eliteAtPct`（波次时长百分比）出现，不占用杂兵队列；第 4 波 35%，第 6 波 30%，第 7 波 30% / 65%。
- 每波前 3 秒降低刷新频率，让玩家调整站位。

### 4.7 Boss：熔炉核心

**登场**：第 8 波开始，屏幕中央落下，1.5 秒无敌动画，播放低频警报。

**基础行为**：缓慢追击玩家，始终保持中距离压力，不贴脸秒杀。

**技能循环**（每 3.5–4.5 秒选择一个）：

1. **碾压突进**
   - 锁定玩家当前位置，地面出现 180×90 红色预警范围。
   - 0.9 秒后向该方向冲刺，造成 24 伤害并留下 2 秒灼烧地面，每 0.5 秒 10 伤害。
   - 撞墙后眩晕 1.2 秒，提供输出窗口。

2. **熔渣弹幕**
   - 0.8 秒蓄力，Boss 中心亮起。
   - 发射 16 发环形弹幕，弹速 180，伤害 12，弹幕之间留可穿越缝隙。
   - 二阶段变为双重环形，但第二轮旋转角度错开，仍保留安全通道。

3. **召唤无人机**
   - 从 Boss 四周生成 4 只蜂群无人机，生命值为当前波次缩放值。
   - 召唤有 0.6 秒传送警告，不直接叠在玩家身上。

**二阶段（生命 ≤ 50%）**：

- 进入时短暂无敌 1 秒，屏幕震动，Boss 外圈变红。
- 攻击间隔缩短 25%，移速 +15%。
- 碾压突进改为连续两次短冲，中间 0.5 秒间隔，每次都有独立预警。
- 不再召唤额外敌人，避免场上实体失控。

**软狂暴（战斗超过 60 秒）**：

- 攻击间隔再缩短 30%，移速 +20%。
- 不增加新弹幕数量，只加快循环，保证画面可读。

**胜利条件**：Boss 生命降至 0，播放爆炸和慢动作，1.8 秒后进入胜利页。

#### 5.4.1 夕阳针：RESET

- **触发条件**：每把武器每次攻击命中至少一个敌人后，独立判定一次，概率 **2%**。同一次散射、穿透或范围攻击即使命中多个目标，也只算一次判定，避免多段攻击暗中放大触发概率。
- **触发限制**：RESET 已激活时不再进行触发判定，避免无限续杯；波次结束时强制清除。
- **持续时间**：基础 **4 秒**；激活期间每次击杀延长 **0.1 秒**，总时长最多延长到 **6 秒**。
- **效果**：
  - 所有武器最终攻速 ×5，即实际冷却再除以 5。
  - 所有伤害 +15%，与其他伤害加成线性相加。
  - RESET 不重置武器冷却，爆发完全来自攻速倍率。
  - RESET 的攻速倍率作用在常规攻速计算之后，不受常规攻速上限限制，但最终冷却下限为 0.08 秒。
- **表现**：触发瞬间播放短促倒带音、屏幕扫描线 / 色差闪动，HUD 出现倒计时；每次击杀增加时长时，倒计时条轻微回弹。期间武器冷却环和开火频率明显加快。
- **设计意图**：不重置冷却，而是用更夸张的攻速倍率制造爆发窗口；通过击杀延长鼓励玩家在 RESET 期间持续清理小怪，形成“越杀越久”的短暂高潮。

#### 5.4.2 夕阳针：光轨追焦

- **名称含义**：摄影中的追焦，加上骑行时留在夜色里的光轨；对应她“边移动边取景”的战斗方式。
- **触发条件**：玩家连续产生移动输入 1 秒后进入「光轨追焦」。只检测 WASD / 方向键输入，不依赖实际位移，避免击退、碰撞或边界卡位造成误判。
- **退出条件**：停止移动后有 1 秒宽限，期间再次移动则保持状态；连续静止满 1 秒后退出。退出后再次移动需要重新累计 1 秒。
- **增益**：
  - 移动速度 +10%，与其他百分比移速加成线性相加。
  - 暴击率 +8 个百分点，受 75% 暴击率上限限制。
  - 与 RESET 可同时生效；RESET 的攻速 ×5 会让这 8% 暴击率更快转化为实际输出。
- **表现**：激活时脚下和身后拖出短促光轨残影，角色周围出现细线相机对焦框；HUD 的被动图标亮起。停下后光轨逐渐消散，1 秒宽限结束完全熄灭。激活、失效各播放一次轻微机械对焦声。
- **设计意图**：第二个被动改变走位节奏，而不是再塞一个随机伤害触发。它让夕阳针保持高风险、高机动的定位，同时补足脆皮角色的生存能力，并给 RESET 提供更稳定的暴击收益。
- **实现**：条件型派生属性，不创建额外实体，不写入存档；波次结束时清除，暂停时冻结计时。

#### 5.4.3 Simon：双被动

**Simon太强了**

- 初始伤害 **+50%**，与其他伤害加成线性相加，常驻生效。该数值由旧基线 +20% 上调，目标是相对旧基线补充约 25% 实际 DPS（1.5 / 1.2）。
- **溢伤弹射**：Simon 的直接伤害击杀敌人时，超出目标剩余生命的伤害的 **25%** 会弹射给 160px 内最近的另一名敌人。
- 每次击杀最多弹射 1 次，弹射伤害不会再触发溢伤弹射，也不会无限连锁。
- 弹射可以正常击杀目标并产生金币掉落；若范围内没有其他敌人，则溢伤直接消失。
- 弹射表现为一条短暂的琥珀色机械火花连接目标，并在命中处炸开小型“BUG 碎片”。

**Simon今天会修的**

- 波次结束后，自动拾取场上所有尚未拾取的金币。
- 每自动回收 **15 枚**未拾取金币，获得 **1 层维修护盾**，最多持有 **2 层**；不足 15 枚的零头不累计。
- 维修护盾跨波保留，直到被消耗；获得新护盾时不会超过 2 层。
- 每层护盾抵挡一次完整的伤害实例，优先于生命和护甲结算；护盾破碎后给予 0.3 秒无敌，避免同一帧被连续伤害瞬间打穿。
- 处理顺序：战斗停止 → 结算 Simon 未拾取金币 → 按回收数量补充维修护盾 → 发放波次完成奖励 → 显示本波金币 / 护盾汇总 → 属性升级 → 商店。
- 金币仍正常进入钱包，不额外增加掉落、不复制金币、不影响商店价格。
- 若场上没有未拾取金币，结算栏显示「Simon 无需修复」，不获得新护盾。
- 设计意图：保留自动拾取的便利性，同时把 Simon 的经济能力变成下一波的生存资源，让他真正承担“修东西”的队友职责。

#### 5.4.4 Junyi：暂时禁用

- Demo 中保留第三张角色卡，但不提供可选状态、初始武器、数值和被动。
- 卡片灰显并显示「能力设计中」；点击只弹出一句提示，不影响当前选择。
- 数据结构保留 `enabled: false`，方便后续补全，不进入可选角色列表。
- 不计入 Demo 的“可玩角色”数量，也不参与平衡与验收。

#### 5.4.5 角色规则

- 外观和职业符号只承担角色表达，不额外生成数值机制。
- 每个可玩角色最终配置 **2 个被动**：夕阳针为 RESET + 光轨追焦，Simon 为两个专属被动；Junyi 后续补齐。
- 角色差异来自基础数值、初始武器和上述被动；不加入主动技能，避免 Demo 系统膨胀。
- RESET 的数值、持续时间、光轨追焦的增益，以及 Simon 的护盾收益需在 M4 阶段通过试玩微调。
- 被动实现方式：
  - RESET 通过 `onAttackHit` 事件触发，每次攻击仅判定一次；击杀时通过 `onKill` 延长持续时间。
  - Simon太强了的溢伤弹射通过 `onKill` 结算，需从伤害系统中拿到溢出伤害值。
  - Simon今天会修的通过 `onWaveEnd` 自动收取金币并生成维修护盾。
  - 光轨追焦通过移动输入与派生属性实时计算，不参与事件随机。
- 波次结束、重开和切屏时清理运行时被动状态，避免带入商店或下一波。

### 6.1 视觉方向

- 首页、商店和结算页可以出现故障终端窗口、代码片段和工位贴纸，但战斗场景保持低对比，保证子弹、敌人和地面预警清晰可读。

### 6.2 动效与反馈

- 玩家受击：白闪 0.1 秒 + 2px 震屏 + 红色暗角脉冲。
- 敌人受击：闪白 + 击退 + 4–8 个粒子；暴击显示更大的黄色数字。
- 击杀：短促爆裂粒子，精英死亡有 0.2 秒慢动作。
- 拾取金币：飞向玩家并产生小型拖尾，数字计数弹跳。
- 升级 / 购买：卡片抬起、描边发光、数值变化处显示 `+` 差异。
- 夕阳针触发 RESET：0.12 秒画面故障切片、轻微色差、扫描线扫过，HUD 倒计时亮起；击杀延长时间时倒计时条回弹，不改变整体明暗。
- 光轨追焦激活：角色脚下出现短促光轨残影和细线对焦框，移动时保留 1–2 帧残影；停下后残影在 1 秒内淡出。强度随画质档位降低，不影响判定。
- Simon 触发溢伤弹射：一条短促琥珀色弧线连到最近敌人，命中点炸出方块碎片；连续击杀时特效错峰播放，避免糊屏。
- Simon 获得维修护盾：金币回收后，护盾层数以金币环形式在角色周围旋转出现；护盾破碎时播放金属碎裂 + 金币散落效果。
- Simon 波次结束收金币：全场金币化作连续拖尾飞向角色，结算栏显示「Simon 已修复 X 枚 / 获得 X 层护盾」；金币多时合并飞行动画，避免卡顿。
- Boss 技能预警：地面红色图形 + 边缘闪烁，禁止仅用颜色作为唯一提示。
- 屏幕震动可关闭；默认强度低。

### 7.3 状态机

```text
BOOT
 → HOME
 → CHARACTER_SELECT
 → PLAYING
 → PAUSED
 → WAVE_CLEAR
 → UPGRADE
 → SHOP
 → PLAYING ...
 → BOSS
 → VICTORY / DEFEAT
 → HOME / CHARACTER_SELECT
```

- `RunState` 与 UI 屏幕状态分离：战斗引擎只关心当前波次和玩家数据。
- 切换屏幕时，战斗引擎不会销毁，Canvas 保持在背景；商店 / 升级页使用半透明遮罩。
- 开始新任务时重置 Run、RNG 种子、实体数组、计时。
- `gameState` 以只读快照暴露给 React；HUD 以约 20Hz 更新，Canvas 以 60Hz 渲染。

### 7.4 战斗循环

- `requestAnimationFrame` 驱动，固定更新步长 `1/60s`，使用累加器处理帧间隔。
- 单帧最多补 3 次更新，防止切后台后大量追帧。
- 渲染与更新分离；游戏逻辑不直接操作 DOM。
- 实体使用简单数组 + 反向遍历删除，暂不引入 ECS。
- 碰撞初期使用圆形包围体，暴力检测并在超过 80 个敌人时启用简单网格分区。
- Canvas 按 `devicePixelRatio` 缩放，限制 DPR 最高 2，避免 4K 屏过度绘制。
- 世界 1600×900 固定，屏幕只做等比缩放与 letterbox。

### 7.5 数据与平衡

- 角色、武器、升级、模块、敌人、波次全部数据驱动，便于后续加内容。
- 角色被动分为事件型和条件型：RESET 通过 `onAttackHit` 触发（每次攻击只判定一次）并通过 `onKill` 延长；Simon 的溢伤弹射通过 `onKill` 结算，自动拾取与护盾通过 `onWaveEnd` 结算；光轨追焦根据移动输入与静止宽限时间实时计算。
- RESET 和光轨追焦属于临时状态，存在运行时 Buff / 派生属性中，不写入存档，也不跨波保留。
- Simon 的维修护盾是跨波状态，必须写入存档，并在消耗或达到 2 层上限时正确截断。
- Junyi 以 `enabled: false` 留在角色表中但不进入可选列表。
- 数值集中在 `data/balance.ts`，不在系统代码中硬编码。
- 随机数使用带种子的 PRNG（如 mulberry32），保存种子，便于复现平衡问题；RESET 的 2% 判定使用同一随机流，避免另开随机源。
- 商店生成权重：
  - 武器 40%，模块 60%。
  - 至少 1 个武器，直到武器槽满。
  - 同一商店不出现重复商品；已满层升级卡不进入卡池。

### 7.6 存档

LocalStorage key：`dimbro.save.v1`

```ts
interface SaveData {
  version: 1;
  savedAt: number;
  run: {
    seed: number;
    characterId: 'sunsetNeedle' | 'simon' | 'junyi'; // Junyi 当前不可存档
    wave: number;              // 下一次要打的波次
    coins: number;
    currentHp: number;
    shields: number;           // Simon 维修护盾，0–2；其他角色为 0
    stats: PlayerStats;
    upgrades: Record<string, number>;
    weapons: Array<{ id: string; level: number }>;
    modules: Record<string, number>;
    totals: { kills: number; damage: number };
  };
}
```

- 在每波开始和离开商店时写入。
- 战斗中关闭页面，继续任务会从本波开始时的状态恢复。
- 存档解析失败：提示存档损坏，提供「开始新任务」，不阻塞启动。
- 胜利 / 失败后清除存档。
- 音乐、音效和震屏设置单独存储，不受对局存档影响。

### 7.7 性能基线

- 目标：1080p、普通集显、Chrome/Safari 最新版，战斗中稳定 60 FPS。
- 实体上限：敌人 60、玩家弹幕 120、敌方弹幕 80、拾取物 100。
- 达到上限时优先减少刷新和粒子数量，不跳过伤害计算。
- 粒子和飘字使用对象池；敌人与子弹在达到规模后再优化。
- 开发者面板（`?debug=1`）显示帧率、实体数、本波剩余刷怪数、当前 RNG 种子。

### 8.3 测试重点

- 伤害公式：护甲减伤、暴击、武器升级乘算；Simon +50% 与 RESET +15% 的加法叠加。
- 角色被动：RESET 在固定随机种子下按攻击次数 2% 触发可复现，攻击多目标只判定一次，攻速 ×5、基础 4 秒、击杀最多延长至 6 秒、Buff 期间不重复触发；光轨追焦的移动 1 秒进入、停止 1 秒退出、暴击上限与移速叠加；Simon 的常驻伤害、溢伤弹射和波次末全收金币 + 护盾生成。
- 维修护盾：15 枚一层的取整、2 层上限、先于生命/护甲结算、破碎无敌、跨波与存档恢复。
- 溢伤弹射：只对直接伤害击杀生效，最多弹射一次且不能循环触发；范围内无目标时不报错。
- 金币结算：普通角色漏捡金币会丢失；Simon 先自动收取，再发完成奖励，最后进入升级与商店。
- 属性汇总：同类加成相加、上限截断、最大生命同步当前生命。
- 商店：槽位满时的替换与退款、重复武器升级、刷新费用递增、商品不重复。
- 波次：计时结束、金币丢失 / Simon 修复、升级卡池耗尽、Boss 波无倒计时。
- 角色选择：Junyi 禁用卡不出现在可选角色中，也不能通过键盘焦点或 URL 参数绕开。
- 存档：版本不匹配、损坏数据、Junyi 存档被拒绝、维修护盾层数恢复、胜利后清除。
- 冒烟测试：夕阳针和 Simon 各跑一遍「新游戏 → 第 1 波 → 升级 → 商店 → 第 2 波」，以及直接调试跳至 Boss 并击杀。

## 9. 风险与取舍

| 风险 | 影响 | 对策 |
|---|---|---|
| 自动索敌打偏 / 玩家不理解目标 | 体验割裂 | 绘制当前目标标记；优先最近敌人；近战扇形范围可视化 |
| 数值成长过强导致后几波无压力 | 失去挑战 | 敌人生命每波 +12%；商店价格与波次经济联调 |
| 敌人过多导致掉帧 | 战斗不可读 | 实体上限、粒子池、简单网格碰撞、出生节流 |
| 普通角色金币拾取漏捡导致经济崩盘 | 构筑失败、Simon 过强 | 最后 5 秒提示未拾取金币；提供磁吸升级；通过试玩控制 Simon 的经济与护盾收益 |
| 2% 的 RESET 长时间不触发，夕阳针体验空转 | 角色手感差 | 显示触发概率与 Buff 倒计时；提供攻速与多武器成长空间；通过调整持续时间而非提高概率来救手感 |
| RESET 攻速 ×5 配合多武器造成弹幕/特效过载 | 掉帧、看不清敌人 | 冷却下限 0.08 秒；同帧合并枪口特效；弹幕达到上限时只限制生成，不跳过伤害 |
| Simon 的溢伤弹射与护盾叠加过强 | 难度骤降 | 弹射只允许一次且伤害 25%；护盾最多 2 层，护盾生成门槛按试玩调整 |
| 多个 UI 页面打断战斗节奏 | 单局过长 | 升级只三选一；商店操作快捷；转场 0.3 秒内 |
| Boss 弹幕看不清 | 挫败 | 高对比预警、固定弹幕缝隙、限制同屏弹幕数量 |
| 浏览器窗口过小 | UI 挤压 | 1280×720 为最低支持，更小尺寸提示放大窗口 |
| 纯程序化美术缺少质感 | Demo 不够吸引 | 统一描边、粒子、灯光、镜头反馈；后续可替换 spritesheet |

### 关键取舍

- **固定单屏战场**，不做滚动地图，换取战斗可读性和开发速度。
- **自动攻击**，不做手动瞄准，让走位与构筑成为主要决策。
- **每波固定 1 次属性升级**，不做经验条，减少 UI 与节奏复杂度。
- **没有主动技能和冲刺**，控制输入数量，避免和自动射击争夺注意力。
- **Boss 只做 1 个但有完整二阶段**，把打磨集中在最终高潮。

## 10. 后续版本方向

1. **内容扩展**：新角色机制、武器合成、更多 Boss、随机事件房。
2. **地图变化**：不同工厂区域、可破坏障碍物、环境陷阱。
3. **局外成长**：角色解锁、图鉴、挑战词条、难度层级。
4. **构筑深度**：武器元素、套装模块、负面词条换取高收益。
5. **体验优化**：手柄、移动端虚拟摇杆、色盲模式、完整原声音乐。
6. **长期模式**：无尽波次、每日挑战种子、排行榜。

## 11. 待确认 / 可调整项

- 夕阳针 / Simon 的基础生命、护甲、移速和初始武器为执行设计基线，可根据试玩微调。

- 选程序员页是否需要局外解锁；当前建议不做，Demo 直接开放夕阳针与 Simon。
- 最低支持分辨率是否保持 1280×720；如主要投屏演示，可提高至 1440×900。
